# Windows 11 Security Hardener v2.0

Профессиональный инструмент для системных администраторов для управления политиками безопасности Windows 11.

## 📋 Описание

Программа позволяет управлять ограничениями для обычных пользователей через удобный графический интерфейс:

- **Блокировка системных компонентов**: RegEdit, CMD, PowerShell, Диспетчер задач, Панель управления
- **Управление приложениями**: Черный список программ, блокировка игр и временных папок
- **Контроль USB**: Запрет записи или полное отключение USB-накопителей
- **Ограничения браузера**: Блокировка расширений, инструментов разработчика, сохранения паролей
- **Журнал событий**: Автоматическое логирование всех изменений

## ⚠️ Требования

- Windows 10/11
- Python 3.8 или выше (для компиляции)
- Права администратора (обязательно!)

## 🚀 Установка

1. Скачайте репозиторий
2. **Щелкните правой кнопкой мыши** на `install.bat`
3. Выберите **"Запуск от имени администратора"**
4. Дождитесь завершения установки

Программа будет:
- Скомпилирована в EXE файл
- Установлена в `C:\Program Files\WinSecHardener`
- Создан ярлык на рабочем столе
- Настроены права доступа (только для администраторам)

## 📖 Использование

1. **Запустите программу от имени администратора** (щелчок правой кнопкой → Запуск от имени администратора)
2. Выберите нужные настройки в соответствующих вкладках
3. Нажмите **"Применить всё"**
4. Некоторые изменения требуют перезагрузки

### Вкладки программы:

#### 🖥️ Система
- Блокировка редактора реестра (RegEdit)
- Запрет командной строки (CMD)
- Ограничение PowerShell
- Блокировка диспетчера задач
- Запрет панели управления и параметров Windows
- Блокировка выполнения (Win+R)

#### 📁 Приложения
- Черный список программ по имени файла (.exe)
- Блокировка игровых платформ (Steam, Epic Games)
- Запрет запуска из временных папок

#### 💾 USB и Сеть
- Режим только для чтения для USB
- Полное отключение USB-накопителей
- Отключение сетевого доступа

#### 🌐 Браузер
- Запрет установки расширений
- Блокировка инструментов разработчика
- Отключение сохранения паролей

#### 📋 Журнал
- Просмотр всех внесенных изменений
- Логирование в файл `C:\ProgramData\WinSecHardener\audit.log`

## 🔒 Безопасность

- Программа требует прав администратора для запуска
- Установочная папка защищена ACL (доступ только администраторам)
- Все изменения записываются в журнал аудита
- Возможность полного сброса настроек

## 🛠️ Технические детали

Программа работает через изменение ключей реестра Windows:
- `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies`
- `HKEY_CURRENT_USER\Software\Policies\Microsoft`
- `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services`
